## 📘 Description

Repository containing the model and support files for the **Bolted Vessel tutorial in ANSYS Workbench (Static Structural)**.

In this course, a structural simulation of a **vessel subjected to internal loading and joined using bolts** is developed using the **Static Structural** environment in ANSYS Workbench. The main objective is to analyze the mechanical behavior of the assembly, evaluate the stress distribution, review the interaction between components, and study the effect of the bolted joint on the structural response of the system.

This tutorial is intended to reinforce concepts related to **mechanics of materials**, **mechanical design**, **bolted joints**, **contact conditions**, and **finite element simulation applied to mechanical assemblies**.

🎥 [Step-by-step video on YouTube](https://youtu.be/o2XyjCXyFVI)

## 📂 Included files

- `geometry/` → CAD geometry of the bolted vessel.
- `workbench/` → **ANSYS Workbench** project file (`.wbpz`) with the configured workflow.
- `results/` → Simulation results for postprocessing in ANSYS.
- 🎥 [Step-by-step video on YouTube](https://youtu.be/o2XyjCXyFVI) → Complete explanation of the procedure.
- 📁 [Project folder on GitHub](https://github.com/adriancrc/Ansys-Tutoriales/tree/main/Recipiente%20Atornillado%20(Static%20Structural))

> **Note:** Large files are managed using **Git LFS**.

## ✨ Features

- Configuration of a **Static Structural** analysis for a mechanical assembly.
- Modeling and evaluation of a **bolted vessel**.
- Definition of **contact interactions** between assembly components.
- Setup of boundary conditions and structural loads.
- Application of internal pressure or equivalent loading on the vessel.
- Evaluation of stresses, deformations, and critical regions.
- Analysis of the behavior of the bolted joint.
- Postprocessing of results to interpret the structural response of the system.

## 🚀 How to install / use

### 🔹 Option 1: Clone with Git LFS

```bash
git lfs install
git clone https://github.com/adriancrc/Ansys-Tutoriales.git
```
Then:

Open the folder:
Bolted Vessel (Static Structural)

Import the .wbpz file into ANSYS Workbench.
Verify:
Assigned materials.
Contact interactions between components.
Boundary conditions.
Applied loads.
Mesh configuration.
Available results for postprocessing.
Solve the model and analyze:
Total deformation.
Equivalent von Mises stress.
Critical regions of the vessel.
Behavior of the bolted joint.
Stress distribution in the cover, body, and bolt region.

### 🔹 Option 2: Download from GitHub

Go to the project folder:

Bolted Vessel (Static Structural)

Download the project files.
Open the project in ANSYS Workbench.

### 🔹 Option 3: Download from Releases

Go to the Releases section.
Download the corresponding .zip file.
Extract the files and open the project in ANSYS Workbench.

## 🎯 Learning objectives

By the end of this tutorial, the user will be able to:

Configure a static structural analysis for a mechanical assembly.
Define contact interactions between parts in ANSYS Workbench.
Apply loads and constraints to a bolted vessel.
Interpret stress and deformation results.
Identify critical regions in an assembly subjected to loading.
Understand the importance of bolted joints in structural behavior.
Relate simulation results to basic mechanical design criteria.
