## 📘 Descripción

Repositorio con el modelo y archivos de apoyo para el tutorial de **Recipiente Atornillado en ANSYS Workbench (Static Structural)**.  

En este curso se desarrolla una simulación estructural de un **recipiente sometido a carga interna y unión mediante pernos**, utilizando el entorno **Static Structural** de ANSYS Workbench. El objetivo principal es analizar el comportamiento mecánico del ensamble, evaluar la distribución de esfuerzos, revisar la interacción entre componentes y estudiar el efecto de la unión atornillada sobre la respuesta estructural del sistema.

El tutorial está orientado a reforzar conceptos de **mecánica de materiales**, **diseño mecánico**, **uniones atornilladas**, **condiciones de contacto** y **simulación por elementos finitos aplicada a ensambles mecánicos**.

## ✨ Características

- Configuración de un análisis **Static Structural** para un ensamble mecánico.
- Modelado y evaluación de un **recipiente atornillado**.
- Definición de **contactos** entre componentes del ensamble.
- Configuración de condiciones de frontera y cargas estructurales.
- Aplicación de presión interna o carga equivalente sobre el recipiente.
- Evaluación de esfuerzos, deformaciones y zonas críticas.
- Análisis del comportamiento de la unión mediante pernos.
- Postproceso de resultados para interpretar la respuesta estructural del sistema.

## 🚀 Cómo instalar / usar

### 🔹 Opción 1: Clonar con Git LFS

```bash
git lfs install
git clone https://github.com/adriancrc/Ansys-Tutoriales.git
```
Luego:

Abre la carpeta:
Recipiente Atornillado (Static Structural)

Importa el archivo .wbpz en ANSYS Workbench.
Verifica:
Materiales asignados.
Contactos entre componentes.
Condiciones de frontera.
Cargas aplicadas.
Configuración del mallado.
Resultados disponibles para postprocesamiento.
Resuelve el modelo y analiza:
Deformación total.
Esfuerzo equivalente de von Mises.
Zonas críticas del recipiente.
Comportamiento de la unión atornillada.
Distribución de esfuerzos en la tapa, cuerpo y región de los pernos.

### 🔹 Opción 2: Descargar desde GitHub

Dirígete a la carpeta del proyecto:

Recipiente Atornillado (Static Structural)

Descarga los archivos del proyecto.
Abre el proyecto en ANSYS Workbench.

### 🔹 Opción 3: Descargar desde Releases

Dirígete a la sección Releases.
Descarga el archivo .zip correspondiente.
Extrae los archivos y abre el proyecto en ANSYS Workbench.

## 🎯 Objetivos de aprendizaje

Al finalizar este tutorial, el usuario podrá:

Configurar un análisis estático estructural para un ensamble mecánico.
Definir contactos entre piezas en ANSYS Workbench.
Aplicar cargas y restricciones en un recipiente atornillado.
Interpretar resultados de esfuerzo y deformación.
Identificar zonas críticas en un ensamble sometido a carga.
Comprender la importancia de las uniones atornilladas en el comportamiento estructural.
Relacionar los resultados de simulación con criterios básicos de diseño mecánico.
